# 模拟器关键决策

上下文版本：`CTX-SIM-REPO-2026.10-v3`

1. `main` 是模拟器唯一权威实现；消费者不得复制源码或公共结构。
2. 当前交付平台是 Linux；Windows/PowerShell/WSL 启动、打包和托管消费者链路已退役。
3. 图像基线是 `1440×1080`；物理 250 Hz；高性能采集上限 200 Hz；性能结论只认 Release 实测。
4. 对外坐标采用 ROS/REP-103 式右手系：世界/odom 与车体为 `+X` 前、`+Y` 左、`+Z` 上；相机 optical 为 `+X` 右、`+Y` 下、`+Z` 前。
5. 云台角在所有公共控制和状态反馈中一致：yaw/pitch 均是绝对角；`pitch=0°` 水平，正值抬头，负值低头。
6. 默认俯仰限位为 `±0.785 rad`，即约 `[-45°,+45°]`；输入超限时由模拟器对称 clamp。
7. 1.x 俯仰定义已退役；不提供自动兼容偏移或符号反转层。这是 2.0.0 主版本变更。
8. 公共兼容边界为 `DaedalusSimSdk 2.x`；布局仍是 `SHM v7 / ABI revision 2`，但 1.x 的 pitch 语义不兼容。
9. 实时云台、图像和场景管理分别使用 `5601/udp`、`5602/tcp`、`5603/udp`。
10. 正式高性能启动显式使用 TCP 原生 RGBA latest-only、完整场景，并禁用主窗口、调试窗口和 UI 相机；`--target-only` 是只渲染活动目标的最大帧率选项，可见模式只用于人工验收。
11. 所有发射入口共用 `ProjectileCooldown`，物理层最大射频 20 Hz。
12. 消费者调试不自动授予模拟器写权限；需提交证据、影响和版本变更并获得用户明确批准。
